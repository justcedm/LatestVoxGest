# FSL Avatar fingerspelling architecture — offline v1

Audit scope: current Avatar worktree, its Avatar Trial action/animation manifests, and Earle's private 12-action handoff. The private GLB enumerates exactly Core3 plus nine candidate clips; none is `FSL_FS_A` through `FSL_FS_Z`. Historical `asl_alphabet.tflite` and other ASL material in the broader repository are recognition-side or unvalidated ASL resources and are **not** Avatar FSL letter evidence. Result: `AVAILABLE=none`, `MISSING=A–Z`, `NEED_FSL_REFERENCE=A–Z`, `NEED_CALIBRATION=A–Z` (26 each). The explicit per-letter statuses are in `AVATAR_FSL_FINGERSPELLING_REGISTRY_V1.json`.

Each letter requires an identifiable FSL-qualified reference and source/version/license record before calibration. A reviewer determines whether it is a static hold or a motion; `static_or_dynamic` is intentionally `UNDETERMINED_FSL_REVIEW` for all 26. Dynamic letters must keep their full motion. `hold_ms` and transition policy stay unset until the source and device readability tests establish values. A missing letter must never be rendered as an invented pose or an ASL fallback.

Proposed spelling scheduler input: normalized Latin-letter name plus a reviewed orthography policy. For `ANNA`, emit `A -> N -> REPEAT_SEPARATOR -> N -> A` after all four referenced letter clips are validated. The repeat separator is a short, FSL-reviewed visual distinction (for example a hold or repositioning policy), **not** an extra alphabet sign and not a hardcoded duration today. A repeated-letter test must prove two visible N tokens rather than an indistinguishable continuous N. Transition rules may retain hand location between letters where reviewed; they must not force full-body neutral after every letter. No overlap: each letter's completion callback and required hold/transition finish before the next begins. Cancellation, replay, clip/hash validation and timeout handling follow the phrase sequencer's single-action queue contract.

Primary use: proper names, unsupported/OOV words, technical terms and explicit spelling requests. Do not spell an ordinary whole sentence by default. Characters, Filipino orthography conventions and digraphs beyond basic A–Z require explicit FSL review. No production LISTEN integration is permitted while the library is empty and unvalidated.

Acceptance gates per letter: source provenance and license, FSL-qualified linguistic review, rig/handshape calibration (and trajectory for a dynamic letter), transition from/to neighboring letters, repeated-letter readability, full-body and active-hand visibility on the Samsung, collision/deformation/snap checks, neutral return, replay, and performance. The A–Z package is a separate Earle workload from the five-concept sentence-enabling tranche.
