# Datasets and Validation

## Primary FSL Source

The current research direction treats **FSL-105** as the primary documented FSL vocabulary authority for the main recognition condition.

FSL-105 provides a documented collection of Filipino Sign Language video samples across 105 classes. Dataset provenance must remain attributed to its original creators.

## Separate Experimental Source

The project has also investigated an audited Mapua transactional FSL dataset for an experimental overlapping-class condition.

The FSL-105 and Mapua conditions must remain separately identified in reporting. Results, temporal contracts, vocabulary, or samples should not be silently mixed.

## Device Captures

Samsung/user/team recordings are used for:

- runtime diagnostics;
- device-domain testing;
- controlled development evidence;
- failure reproduction.

They must not become authoritative FSL linguistic ground truth merely because they were recorded by the development team.

## Avatar Validation

Technical playback is not equivalent to linguistic validation.

An Avatar action may be:

- technically playable;
- visually acceptable to the development team;
- still pending qualified FSL/expert validation.

Documentation must preserve that distinction.

## Phrase and Fingerspelling Expansion

Phrase intents such as ASK_NAME have been explored, but phrase-level recognition requires complete-motion segmentation and qualified FSL validation.

Personal names should only be fingerspelled using a validated FSL manual-alphabet source. English word order must not be assumed to equal FSL grammar.
